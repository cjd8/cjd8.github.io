Another couple of weeks, another new kernel release. Not many interesting things
from me, just some Kconfig cleanups, IIO patches and a syzbot fix in the NILFS
filesystem. What is odd is that the number of Reviewed-by tags from me is higher
than the number of patches...

## The additions

- Added support for the Microchip MCP47A1 Digital-to-Analog converter

## The cleanups

- Cleaned up the TI OPT3001 ambient light sensor driver (devm_\*, guard(mutex)(), function refactoring)
- Replaced a custom macro with `str_plural()` in ext4, thanks to Coccinelle

## The fixes

- Fixed an infinite loop in the NILFS2 filesystem reported by syzbot. An operation would hang if a terminal error like -EROFS was encountered.
- Added missing configfs_remove_default_groups() calls to the MIDI2 USB device. These missing calls were causing memory leaks on driver unbind.
- Added several missing `select REGMAP` lines to Kconfig entries, preventing build failures.

## Reviews

I managed to add my Reviewed-by tag to 43 patches, spanning the IIO and counter subsystems.
